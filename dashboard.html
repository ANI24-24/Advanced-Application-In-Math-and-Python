Windowing and missing values

The 7-day rolling mean and the 30-day minimum expanding σ leave gaps at the start of the year. Each column is filled by its own rule instead of dropping a month of data.

Computed value NaN Filled
  • Rolling mean, days 1–6Filled with the mean of the days available so far, the same calculation on a shorter window.
  • Expanding σ, days 1–29Back-filled with the first valid value on day 30, since σ is unstable on so few points.
  • Nothing hiddenAn is_filled column flags all 29 filled rows, so they can be told apart later.
